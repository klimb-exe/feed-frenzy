
# 🎮 Feed Frenzy

### 30 Seconds. One Feed. Endless Distractions.

A fun, interactive browser game inspired by LinkedIn's feed culture.

Instead of writing another complaint about engagement bait, I turned the idea into a playable experiment!

## 🚀 Play the Game

**[🎮 PLAY FEED FRENZY](https://feed-frenzy-linkedin-game.pages.dev/)**

## 🎯 About the Project

Feed Frenzy is a lightweight, 30-second browser game that humorously explores the experience of navigating a social media feed.

**The challenge:** Survive the feed, make quick decisions, and see how well you perform before the timer runs out!

## 🛠️ Tech Stack

- **HTML5** — Game structure
- **CSS3** — Styling and layout
- **JavaScript** — Game logic and interactions
- **Cloudflare Pages** — Hosting and deployment
- **GitHub** — Source code and version control

## 💻 Run Locally

1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Start playing!

## 💡 Why I Built This

Because sometimes the best response to an algorithm is to build something more entertaining than complaining about it.

**Less scrolling. More building.**
